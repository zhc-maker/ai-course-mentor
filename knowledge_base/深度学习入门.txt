深度学习入门指南

第一章：什么是深度学习

深度学习是机器学习的一个子领域，它使用多层神经网络来学习数据的层次化表示。
与传统机器学习方法不同，深度学习能够自动从原始数据中提取特征，而不需要人工设计特征工程。

核心概念：
1. 神经元：受生物神经元启发的计算单元，接收输入、加权求和、通过激活函数输出
2. 层：多个神经元组成一层，深度学习模型通常包含多个隐藏层
3. 激活函数：引入非线性，常见的有 ReLU、Sigmoid、Tanh
4. 损失函数：衡量模型预测与真实值之间的差距，如 MSE、交叉熵
5. 优化器：通过梯度下降更新参数，如 SGD、Adam

第二章：PyTorch 基础

PyTorch 是目前最流行的深度学习框架之一，由 Facebook AI Research 开发。
它的核心特点是动态计算图，使得调试更加方便，也更符合 Python 编程习惯。

张量（Tensor）是 PyTorch 中最基本的数据结构，类似于 NumPy 的 ndarray，
但可以在 GPU 上加速计算。

第三章：LLM 大语言模型

大语言模型（Large Language Model）是基于 Transformer 架构的深度学习模型，
通过在海量文本数据上预训练，获得了强大的语言理解和生成能力。

常见的 LLM 包括：
- GPT 系列（OpenAI）
- LLaMA 系列（Meta）
- Qwen 系列（阿里云）
- DeepSeek 系列（深度求索）

QLoRA 是一种高效的微调技术，通过 4-bit 量化和低秩适配器，
使得在消费级显卡上微调大语言模型成为可能。

第四章：RAG 检索增强生成

RAG（Retrieval-Augmented Generation）结合了信息检索和文本生成两大技术。
它的工作流程是：
1. 将知识库文档分块并向量化
2. 接收用户查询后，在向量库中检索最相关的文档片段
3. 将检索结果注入 prompt，交给 LLM 生成最终回答

这种方法可以有效减少 LLM 的幻觉问题，让回答更加准确可靠。
